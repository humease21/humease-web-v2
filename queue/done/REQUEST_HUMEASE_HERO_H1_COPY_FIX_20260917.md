## 1. 배경

`www.humease.com` 홈 화면의 Hero H1 문구에 대해 디자인 피드백이 접수됐다.

- 대상 요소: `h1.display-hero-ko` (Hero 섹션, `#main > section.relative > div.shell > div.max-w-[...] > div > h1`)
- 현재 문구: `복잡한 데이터와 아이디어를, 실제로 작동하는 기술로.`
- 요청 문구: `복잡한 데이터와 아이디어를 실제로 작동하는 기술로`

즉 앞쪽 쉼표(,)와 끝 마침표(.)를 제거한다. 그 외 줄바꿈·스타일·태그 구조는 변경하지 않는다.

## 2. 완료 조건

1. `h1.display-hero-ko`의 렌더링 텍스트가 정확히 `복잡한 데이터와 아이디어를 실제로 작동하는 기술로`가 된다 (쉼표·마침표 없음).
2. 해당 문구를 참조하는 다른 위치(예: 메타 태그, OG 설명, 다른 페이지의 동일 인용문)가 있다면 함께 확인하되, **범위를 벗어난 문구·문단까지 임의로 재작성하지 않는다.**
3. 레이아웃·줄바꿈(`<br/>` 등)이 있다면 기존 줄바꿈 지점을 유지하거나, 문구가 짧아진 만큼 자연스럽게 재배치한다. 폰트 크기·line-height 등 스타일 변경은 하지 않는다.
4. 타입체크·린트 통과.

## 3. 참고 — 원본 피드백 스냅샷

```
URL: https://www.humease.com/
Selector: h1.display-hero-ko.mt-7
Text (before): 복잡한 데이터와 아이디어를, 실제로 작동하는 기술로.
Text (after 요청): 복잡한 데이터와 아이디어를 실제로 작동하는 기술로
```

## 4. 범위 밖
