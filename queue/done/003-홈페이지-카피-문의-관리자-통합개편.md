```text

↓
AI / AX
```

### 2-2. 방문자가 즉시 이해해야 할 내용

첫 화면과 주요 페이지에서 방문자가 바로 이해해야 하는 것

- 휴미즈는 기업 데이터와 AI를 함께 다루는 Enterprise IT·AX 전문 기업
- Enterprise Data는 보관만이 아니라 검색·통제·컴플라이언스·eDiscovery까지 포함
- AI는 단순 도입이 아니라 실제 업무와 서비스 구현까지 연결
- Arctera 제품은 기업 커뮤니케이션 보존·감독·조사 영역을 지원
- 휴미즈는 Arctera 공식 파트너가 아님
- 휴미즈는 직접 AI 서비스를 기획·설계·개발한 경험이 있음
- 프로젝트 상담을 온라인으로 바로 접수 가능

H1/H2 및 시각적으로 대형 타이포그래피로 표시되는 문구는 다음 형식을 우선한다

- 명사형
- 대조형
- 선언형
- `A에서, B로`
- `A를 넘어, B로`
- `A · B · C`
- 짧은 핵심 구문

금지

```text
~합니다
~됩니다
~있습니다
~할 수 있습니다
~해야 합니다
~드립니다
~주세요
```

대형 제목에서 질문형도 최소화한다

### B. 마침표

사용자에게 보이는 **마케팅 카피** 끝에는 원칙적으로 `.`를 붙이지 않는다

대상

- H1
- H2
- H3
- Hero lead
- Section lead
- 카드 설명
- CTA 설명
- 포트폴리오 summary

예외

- 법적 고지
- Arctera 관계 고지
- 개인정보 안내
- 긴 FAQ 답변
- metadata description
- SourceNotes
- 공식 출처 문구

Arctera 관계 고지는 현재 검증 계약을 깨지 않도록 원문 유지

### C. 문구 스타일

우선 사용하는 동사

- 보존

# 3-2. 의미 단위 반응형 줄바꿈

현재 전역 CSS

```css
h1, h2, h3, p, li, dt, dd {
  word-break: keep-all;
  overflow-wrap: anywhere;
}
```

현재 구조는 모바일에서 영문 제품명이나 한글 어절이 어색하게 분리될 위험이 있음

### 원칙

PC에서 의미 단위가 명확한 Hero/H2는 의도된 줄바꿈을 적용한다

예

```text
기업 데이터에서,
AX 실행까지
```

설명도 의미 단위로 구성

```text
기업 데이터의 보존·통제·컴플라이언스부터
AI 서비스 설계와 구현까지

휴미즈는 20년 이상의 Enterprise IT 경험을
실제 AX 실행으로 연결합니다
```

화면에서는 마침표 없이 렌더링

### 구현

`CinematicHero.titleKo`가 현재 `string`이므로 필요 시 기존 사용처를 깨지 않는 범위에서 아래처럼 확장 가능

```ts
titleKo: React.ReactNode
```

또는 별도 `titleLines` 지원

중요

- `<br>` 난사 금지
- 의미 단위 `span` 우선
- 모바일에서 PC 강제 줄바꿈을 그대로 강요하지 않음
- heading에서는 `overflow-wrap:anywhere`로 영문이 단어 중간 분절되지 않도록 별도 규칙 검토
- `hyphens: none`
- 긴 제품명은 공백 단위 자연스러운 wrap 허용
- `Enterprise Vault Capture (formerly Merge1)` 전체를 모바일에서 `nowrap` 처리하지 말 것

검증 viewport

- 320px
- 390px
- 430px
- 768px
- 1440px
- 1920px
