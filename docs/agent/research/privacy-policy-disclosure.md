# 개인정보 처리방침 공개 의무 — 임시 축소 홈페이지 Footer 판단 근거 (2026-10-26)

## 결론
- 문의 폼으로 개인정보를 수집하므로 개인정보 처리방침은 홈페이지에 **지속적으로 게재**해야 한다(개인정보 보호법 제30조 제2항, 시행령 제31조).
- 동의 모달 안의 링크만으로는 "지속적 게재"로 보기 어렵다 — 방문자가 문의 폼을 열지 않으면 보이지 않는다.
- 개인정보보호위원회 처리방침 작성지침은 처리방침 링크를 글자 크기·색상 등으로 다른 고지와 구분해 표시하도록 권고한다.
- 따라서 "Footer 로고만" 요구와 충돌한다. 최소 노출안: Footer 에 로고 + `개인정보처리방침`(강조) 링크 1개. 이용약관은 법정 공개 의무가 없어 문의 동의 UI 와 개인정보처리방침에서 접근 가능하면 충분하다.
- 회사 정보(상호·대표자·사업자번호 등)는 통신판매업이 아니므로 표시 의무 대상이 아니라고 판단한다(전자상거래법상 표시 의무는 통신판매업자 대상).
