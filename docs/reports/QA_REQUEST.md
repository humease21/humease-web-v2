### 2-3. 경력 문구 — 재승인 필요

기존 사이트 description 의 **"Microsoft MVP 출신 전문가"** 는 개인 경력인지 법인 경력인지 구분되지 않은 채 회사 설명에 쓰이고 있었습니다.

회사소개 페이지는 "Enterprise IT와 데이터 컴플라이언스에 대한 실무 경험" 이라는 중립 문구만 씁니다.

→ 표기할지, 표기한다면 "전문가 개인 경력" 항목으로 분리할지 결정이 필요합니다.

### 2-4. 브랜드 일관성 (U05)
