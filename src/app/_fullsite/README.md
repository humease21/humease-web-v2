# _fullsite — 임시 축소 운영 중 보존된 기존 공개 페이지

`_` 로 시작하는 폴더는 Next.js App Router 의 private folder 라 라우팅·빌드 산출물에서 제외된다.
임시 축소 운영(2026-10-26, `src/content/site-mode.ts`) 동안 기존 홈·회사소개·사업영역·Arctera·포트폴리오·인사이트·별칭 페이지 소스를 여기 보관한다.

- 원복의 기준은 이 폴더가 아니라 태그 `humease-fullsite-2026-10-26` 이다 → `docs/ops/TEMP_SITE_RESTORE.md`
- 이 폴더는 참고·부분 복원용이다. 원래 위치는 `src/app/(site)/` 이다.
